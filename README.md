# 日语五十音

一个离线的日语五十音学习工具：清音 / 浊音 / 拗音三张表，点击任意假名播放发音，
点击行、列标题或左上角播放按钮可批量连播，右上角一键切换平假名 / 片假名显示。

## 特点

- **完全离线**，不申请任何权限，不联网
- **依赖极简**，运行时只有 `androidx.appcompat` 一个依赖
- 支持 Android 8.0（API 26）及以上

## 构建

```bash
./gradlew assembleDebug      # 调试包
./gradlew lintDebug          # 静态检查
```

需要 JDK 21 与 Android SDK（compileSdk 37）。

## 数据结构

假名数据在 `app/src/main/assets/kana.json`，每条包含：

| 字段      | 含义                                 |
|---------|------------------------------------|
| `ping`  | 平假名                                |
| `pian`  | 片假名                                |
| `luoma` | 罗马音，同时用作 `assets/<luoma>.mp3` 的文件名 |

三张表由 `KanaData` 生成。注意 yi/ye/wi/wu/we 这 5 个位置在现代日语中不存在，
在 `buildQingTable()` 里按下标标记为不可点击（36/38/46/47/48，对应表中的 50/52/62/63/64），
**调整 kana.json 的条目顺序会让这些下标错位**，改动数据后请对照检查。

## 音频素材

`app/src/main/assets/` 下的 mp3 为假名发音音频。

> **待补充**：这些音频的来源与授权状态尚未确认。如果你计划分发本应用，
> 请先核实音频素材的版权归属，或替换为自行录制 / 公共领域的素材。
